# AvaProxy

**Simple clients. Servers that run anywhere. Built for real network conditions.**

Runs on inexpensive hosting or scales to VPS and dedicated servers.  
Built on the Ava VPN protocol.

AvaProxy is designed to operate in constrained environments while taking advantage of stronger infrastructure when available.

---

## What is AvaProxy?

AvaProxy is a client–server VPN system built for reliability in real-world network conditions.

It is designed around a custom VPN protocol (Ava) that supports multiple transport methods and maintains encrypted connectivity across unstable or constrained networks.

The system includes:

- **AvaProxy Client (Android & Windows)** – Simple applications for secure connections  
- **AvaProxy Server** – Deployable backend that runs on **low-cost hosting or scales to VPS and dedicated infrastructure**

## Deployment Model

AvaProxy Server is designed to be flexible in where it runs:

- **🟢 Inexpensive shared hosting (low-cost environments)**
- **🟡 VPS environments (scalable performance)**
- **🔵 Dedicated servers and cloud infrastructure (advanced deployments)**

This allows the system to start small and scale as needed without changing the core architecture.

## Key Capabilities

- Encrypted VPN connections using the Ava protocol

- Maintains connectivity in restricted or unstable networks  
- Lightweight server deployment options  
- Scalable architecture from simple hosting to high-performance infrastructure
